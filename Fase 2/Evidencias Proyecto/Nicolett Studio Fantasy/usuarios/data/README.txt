Chile administrative divisions data

The chile_dpa.json dataset is adapted from resumen.json in
vicentezaror/regiones-chile at commit 626f98608d95c786b688a4de33de3f70efb10f43:
https://github.com/vicentezaror/regiones-chile/blob/626f98608d95c786b688a4de33de3f70efb10f43/resumen.json

The upstream project cites INE, Wikipedia, and Gobierno de Chile as references.
The dataset includes 16 regions, 56 provinces, and 346 communes.
